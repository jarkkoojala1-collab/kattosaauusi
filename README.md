# Kattokartta - tuulensuunta ja puuskat

Muutokset:
- Ennustenäkymän tuulitieto näyttää nyt tuulen suunnan.
- Tuulen nopeuden perässä näytetään puuskanopeus sulkeissa, jos data on saatavilla.
- Esitystapa:
  - Tuuli: L 270°, 4.2 m/s (7.1 m/s)
- Muuta toiminnallisuutta ei muutettu.
- Edellisen version haku-, pinnoituskartta- ja FMI-tutkakorjaukset säilyvät mukana.

Render-asetukset:

Build Command:
npm run render-build

Start Command:
npm start
